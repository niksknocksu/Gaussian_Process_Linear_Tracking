# Gaussian Process for Linear Object Tracking
A toy object problem for tracking with Gaussian processes. Gaussian process is a data-based approach for inferring model dynamics. Hence, instead of using a specific model and tuning various parameters, a sliding window mechanism for inferring trajectory is used. This also makes prediction easier since instead of a point estimate, a Gaussian process is a joint distribution over infinite family of functions.
